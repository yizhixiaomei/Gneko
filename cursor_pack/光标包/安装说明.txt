像素猫光标包 · 安装说明
========================================

一、一键安装（推荐）
----------------------------------------
1. 把整个“光标包”文件夹解压 / 放到一个固定位置（装好后不要挪动，
   否则光标会失效）。
2. 双击运行里面的  安装.bat  。
   - 脚本会自动把光标复制到当前用户目录并注册，不需要管理员权限。
   - 看到 “Done. The pixel-cat cursor scheme has been applied.” 即安装完成，
     光标随即生效。
3. 想恢复系统默认光标：双击  卸载.bat  即可（会删除已注册的光标并还原默认）。


二、文件对照（主方案，13 个）
----------------------------------------
文件名              对应系统状态            设置面板里的名称
Arrow.cur           正常选择                正常选择
Help.cur            帮助选择                帮助选择
AppStarting.ani     后台运行（动画）        后台运行
Wait.ani            忙 / 等待（动画）       忙
Hand.cur            链接选择                链接选择
NWPen.ani           手写（动画）            手写
SizeWE.ani          水平左右调整（动画）    水平调整
SizeNS.ani          垂直上下调整（动画）    垂直调整
SizeNWSE.ani        左上↔右下调整（动画）   左上右下对角线调整
SizeNESW.ani        右上↔左下调整（动画）   右上左下对角线调整
SizeAll.ani         移动（动画）            移动
No.cur              不可用（禁止）          不可用
IBeam.cur           文本选择（输入框）      文本选择

备用方向\（7 个动画）
----------------------------------------
right.ani / down.ani / dwleft.ani / dwright.ani
rtogi.ani / utogi.ani / dtogi.ani
这些是同一套素材的其余朝向，主方案已各取一组；如果觉得某个方向猫头朝向反了，
可以到“鼠标属性 → 指针”里手动换成备用方向里的同名 ani。


三、手动逐个设置（不用脚本时）
----------------------------------------
1. 按 Win + R，输入 control mouse 回车（或：设置 → 蓝牙和设备 → 鼠标 →
   其他鼠标设置）。
2. 切换到“指针”选项卡。
3. 在列表里逐个选中状态，点“浏览”，按上面的对照表选择本文件夹里的
   cur / ani 文件。
4. 全部选完后，点“另存为”，给方案起个名字（例如“像素猫”），保存。
5. 点“应用”“确定”即可生效。


四、重新生成 / 调整热点
----------------------------------------
生成脚本在上一级目录：_make_cursors.py
- 帧列表、热点坐标都在脚本里的 MAIN / EXTRAS_MAP 字典中，改完运行：
    python _make_cursors.py
- 校验脚本：_validate.py（检查 cur/ani 结构、热点和帧数是否正常）。
- 光标为 32×32，动画帧间隔约 200ms（脚本里 FRAME_RATE 可调，单位 1/60 秒）。
